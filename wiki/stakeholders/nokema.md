# NOKEMA GmbH

Project partner on the Phase II [[building-permits]] project. The report names NOKEMA as one of the two project partners alongside [[byte-studio]], with the function "Projekteinreichung" (project submission) [(Building Permits report, p. 9)](../sources/p2-building-permits.md). The firm is represented in the project team by Marcel Muri, dipl. Architekt ETH und Planer FSU [(Building Permits report, p. 32)](../sources/p2-building-permits.md).

## Role in the sandbox

The report's case-study box states the setup in one sentence: *"NOKEMA submitted the project proposal and implemented it together with technology partner Byte Studio, specialist partner Gossweiler Ingenieure AG and implementation partner Stadt Kloten as part of the Innovation Sandbox."* [(Building Permits report, p. 32)](../sources/p2-building-permits.md) The co-partners are [[byte-studio]], [[gossweiler-ingenieure]], and [[stadt-kloten]]. The report describes NOKEMA's own contribution as project submission and joint implementation; it does not attach one of the five partner-role slugs to the firm, so this page leaves `partner_role` unset.
