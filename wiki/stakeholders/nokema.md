# NOKEMA GmbH

Project partner on the Phase II [[building-permits]] project. The report names NOKEMA as one of the two project partners alongside [[byte-studio]], with the function "Projekteinreichung" (project submission) [(p2-building-permits p. 9)](../sources/p2-building-permits.md). The firm is represented in the project team by Marcel Muri, dipl. Architekt ETH und Planer FSU [(p2-building-permits p. 32)](../sources/p2-building-permits.md).

## Role in the sandbox

The report's case-study box states the setup in one sentence: *«Die Firma NOKEMA hat den Projektvorschlag eingereicht und gemeinsam mit dem Technologiepartner Byte Studio, dem Fachpartner Gossweiler Ingenieure AG sowie der Umsetzungspartnerin Stadt Kloten im Rahmen der Innovation-Sandbox umgesetzt.»* NOKEMA submitted the project proposal and implemented it jointly with technology partner [[byte-studio]], specialist partner [[gossweiler-ingenieure]], and implementation partner [[stadt-kloten]] within the Innovation Sandbox [(p2-building-permits p. 32)](../sources/p2-building-permits.md). The report describes NOKEMA's own contribution as project submission and joint implementation; it does not attach one of the five partner-role slugs to the firm, so this page leaves `partner_role` unset.
